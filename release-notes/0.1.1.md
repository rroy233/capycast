# Release v0.1.1

## Highlights

本版本完善了电视端的应用更新体验，支持自动检查更新、查看完整更新日志、显示下载进度并校验安装包；同时改进电视遥控器导航，并提升 Android 手机通过 DLNA 投屏时的兼容性。

## ✨ New Features

- **应用内更新**：在「设置 → 应用更新」中查看可用版本、更新说明、下载进度和安装状态；直连下载失败或长时间没有进度时，会自动切换备用下载源。
- **启动时检查更新**：开启自动检查后，应用会在启动时检查新版本，并在发现更新时提示。
- **Beta 通道选择最新版本**：Beta 通道会同时比较 Beta 版和正式版，选择 `versionCode` 更高的版本；正式版发布后，Beta 用户也可以收到正式版更新。
- **电视端浏览更新日志**：可使用遥控器打开完整更新日志，在内容中移动焦点并滚动查看。

## 🐛 Bug Fixes

- 修复设置页、应用更新页及弹窗中的遥控器焦点恢复和方向键导航问题。
- 修复 Android 手机通过 DLNA 投屏时的设备识别和连接兼容性问题；设备现在以通用的 CapyCast DLNA 设备信息对外提供服务。

## ⚠️ Breaking Changes

- 在首页按返回键会直接退出应用，不再需要再次按返回键确认。
