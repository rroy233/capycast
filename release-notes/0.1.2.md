# Release v0.1.2

## Highlights

本版本重点改善电视端的遥控器操作体验，并新增播放内容记忆与继续播放入口；设置页和应用更新页的焦点导航也更加清晰。

## ✨ New Features

- **记忆播放内容**：在「设置 → 播放偏好」中开启后，应用会保存最近投屏内容；播放结束或下次启动时，可从首页选择「继续播放」。关闭该选项会清除已保存的播放记录。
- **播放结束返回首页**：启用记忆播放内容后，投屏或播放结束会自动回到首页，并保留继续播放入口，方便重新开始最近的内容。

## 🐛 Bug Fixes

- 修复电视端返回键的页面层级处理问题：会依次关闭弹窗、控制面板、帮助页、更新日志和设置页，减少误退出应用的情况。
- 修复播放过程中按返回键可能直接退出应用的问题；现在会先显示停止投屏确认，确认后停止播放并返回首页。
- 改进设置页和应用更新页的遥控器焦点导航：设置项可逐项聚焦，开关支持整行切换，更新页面打开时定位到顶部，较长的更新日志支持按方向键逐步滚动。

## ⚠️ Breaking Changes

- **首页退出方式调整**：首页按返回键会显示“再按一次返回键退出”，需要在 5 秒内再次按返回键退出应用。
