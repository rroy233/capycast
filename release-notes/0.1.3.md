# Release v0.1.3

## Highlights

本版本为电视端带来弹幕播放与直播投屏：投屏视频和直播间都能同步显示弹幕，并新增倍速播放与遥控器快速跳转；同时支持通过 Media3 硬件解码播放杜比视界片源，并提供可在局域网查看的播放诊断报告。

## ✨ New Features

- **弹幕播放**：投屏视频会同步显示 B 站弹幕，弹幕时钟跟随播放进度，暂停、缓冲和跳转时不会错位。
- **弹幕开关与设置**：播放控制栏可一键开关弹幕；「播放设置 → 弹幕设置」可调整智能云屏蔽（关/低/中/高）、显示区域、同屏数量、不透明度、字号和滚动速度。
- **直播投屏**：支持将 B 站直播间投屏到电视（需先在电视端登录 B 站账号），自动选择当前画质下的可播线路，播放异常或卡顿时切换到更流畅的备用线路，并给出「已自动切换至更流畅线路」提示。
- **直播画质与直播弹幕**：播放控制栏新增直播画质入口，可手动切换服务端提供的画质档位；直播间聊天弹幕同样会滚动显示，控制栏信息简化为「直播 · 画质」。
- **倍速播放**：支持 0.5×、0.75×、1×、1.25×、1.5×、2× 六档速度，弹幕速度会跟随视频一起变化；非正常速度时控制栏按钮高亮提示。
- **遥控器快速跳转**：控制栏隐藏时，左右方向键可直接调整进度，长按会自动加速（从 10 秒起，每秒提升约 1.5 倍，单次最多 2 分钟）；松开约 1.2 秒后自动生效，也可按 OK 立即确认。触摸屏横向滑动遵循同一套加速规则。
- **杜比视界播放**：杜比视界片源改由硬件解码器直出，避免丢失 10-bit HDR 信息，并在清晰度列表中显示「Dolby Vision」「HDR」标识；杜比全景声音轨也可在音轨列表中选择。
- **播放诊断报告**：在同一局域网访问 `http://<电视 IP>:8098/playback` 可查看设备解码能力、轨道选择、播放时间线和 libVLC 原生日志，`/device` 可查看电视支持的解码器与 HDR 能力。播放地址签名、Cookie 和投屏内容会自动脱敏，反馈问题时可直接附上报告。

## 🐛 Bug Fixes

- 修复部分电视起播后黑屏或没有画面：视频输出异常时会自动重建播放器并从当前进度继续播放，只尝试一次以避免反复重启。
- 修复弹幕抖动和提前消失：弹幕改为跟随播放进度计时，使用实际渲染画面区域计算滚动距离。
- 修复直播播放时轻触屏幕无法重新唤出控制栏。

## ⚠️ Breaking Changes

- **播放控制栏布局调整**：「±10 秒」快捷按钮已移除，音轨选择移入「播放设置」，控制栏改为清晰度、倍速、弹幕和设置入口。
- **左右方向键行为变化**：控制栏隐藏时，左右方向键不再唤出控制栏，而是直接调整播放进度；上下方向键和 OK 键仍会唤出控制栏。
- **杜比视界需要硬件解码**：杜比视界片源不再回退到软件解码，电视缺少硬件杜比视界解码器时会提示播放失败。此时可在清晰度列表中选择 HDR、4K 等其他档位。

## 使用提示

- 弹幕默认开启，不想观看时可在播放控制栏点击弹幕按钮关闭，设置会被记住。
- 直播内容不支持进度跳转与倍速播放，相关按钮会自动隐藏或提示不支持。
