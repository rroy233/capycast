# Release v0.1.4

## Highlights

本版本修复部分视频和番剧投屏后直接提示失败、无法播放的问题。

## 🐛 Bug Fixes

- **修复部分内容无法投屏播放**：当 B 站播放接口把杜比音轨、视频流等可选字段返回为空值时，旧版本会把它当成解析失败并中断播放。现在这类字段为空会按「该内容不提供」处理，视频可以正常起播。
- **杜比片源不受影响**：杜比音轨与杜比视界片源在接口正常返回时仍照旧识别，清晰度和音轨列表中依然可以选择。

## 使用提示

- 如果在 0.1.3 上遇到某部视频或番剧投屏后立刻提示失败，升级到 0.1.4 后直接重试即可，无需清除数据或重新登录电视端账号。
