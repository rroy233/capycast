# Release v0.1.5

## Highlights

本版本让番剧、电影、电视剧等 B 站 PGC 内容也能正确投屏播放，并修复了 HDR 片源灰蒙蒙的问题；投屏记录现在会同步到 B 站观看历史。

## ✨ New Features

- **番剧 / 影视投屏**：番剧、电影、电视剧、纪录片、国创、综艺等 PGC 内容现在按正确的播放接口解析和起播，能取到当前账号可播的最高画质，并支持弹幕和播放记录。
- **播放历史同步**：投屏的视频历史、播放进度与直播记录会同步到 B 站账号，方便续播；默认开启，可在「设置 → 同步播放记录到 B 站」中关闭。

## 🐛 Bug Fixes

- **HDR 片源灰蒙蒙**：HDR10 片源改由硬件解码直出，色彩不再发灰失真。
- **画质名称显示**：「大视界 4K」「大视界 4K HDR10」等新增档位现在正确显示服务端官方名称，不再显示成普通编号。

## ⚠️ Breaking Changes

- **HDR 需要硬件解码**：HDR10 片源不再回退到软件解码。电视缺少硬件 HDR 解码器时，HDR 档位可能无法播放，可在清晰度列表选择 4K、1080P 等其他档位。
