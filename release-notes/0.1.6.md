# Release v0.1.6

## Highlights

本版本修复了投屏视频长时间播放或跳转进度后音画不同步的问题，并上线项目官网：可以在网页上查看功能介绍、常见问题和下载入口。

## ✨ New Features

- **项目官网**：访问 `https://rroy233.github.io/capycast/` 可查看功能说明、界面截图、常见问题与更新日志，并直接下载安装包。下载页提供 GitHub 官方地址和两个加速镜像，会自动检测并标出当前网络下较快的源，手机浏览器也能正常浏览。

## 🐛 Bug Fixes

- **音画不同步**：普通点播视频改用与 HDR、杜比视界相同的播放内核，音频和视频由同一时间线驱动，播放一段时间或多次快进快退后不再出现声音和画面逐渐错位。
- **跳转后画面与声音错位**：快进快退确认后只执行一次实际定位，避免连续跳转造成的画面与声音、弹幕不一致。

## 使用提示

- 遥控器快进快退时，预览阶段画面停留在当前位置，进度条先行移动；松开约 1.2 秒或按 OK 确认后画面才跳到目标位置，弹幕也会同步对齐。
- 直播投屏和仅提供单一视频流的旧片源仍使用原有播放方式，不受本次调整影响。

## ⚠️ Breaking Changes

- **点播视频只使用电视的硬件解码**：普通点播视频现在完全交给电视的系统解码器播放，不再在硬件不支持时退回软件解码。电视缺少对应编码的硬件解码能力时（部分老电视的 AV1、HEVC 高画质档位），原本可勉强播放的片源可能提示播放失败，此时可在清晰度列表中换用其他档位。
