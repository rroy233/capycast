# Release v0.2.0

## Highlights

本版本重做了电视端界面：首页、侧边栏、设置页与播放控制栏统一为深色玻璃风格，首页大图会随「最近投屏」的焦点切换；同时新增点播视频字幕与四角画面校准，并首次提供可自行关闭的崩溃与使用数据开关。安装包体积也从约 58 MB 降到约 18 MB。

## ✨ New Features

- **全新界面风格**：首页、侧边栏、弹窗、按钮和播放控制栏使用同一套深色玻璃材质，整体配色由高饱和粉色改为低饱和冷色；宽屏下页面内容改为居中窄栏排列，品牌标识改用矢量绘制，电视桌面的应用横幅换成 16:9 横版图。
- **首页联动最近投屏**：焦点移到「最近投屏」中的某条记录时，首页大标题、背景封面和主按钮会一起切换到这一条，并显示「刚刚」「N 分钟前」「昨天」等相对时间。
- **悬浮侧边栏**：在页面左边界按左键即可呼出侧边栏，它以浮层形式覆盖在当前页面上、背景自动变暗，按返回键或右键收起。
- **设置页重新分区**：分成账号信息、软件信息、设备信息、隐私与数据四块。账号区用平台卡片显示登录状态，未登录时只保留一个扫码登录入口；软件版本会同时显示 Android 版本号，例如 `0.2.0 (18)`。
- **扫码登录改为首页弹窗**：登录不再是进入应用前的一整页，二维码弹窗直接覆盖在首页上，可以随时关闭；未登录时以访客身份仍能看到最近投屏并使用投屏帮助。
- **点播视频字幕**：投屏视频会显示 B 站字幕，人工字幕与 AI 字幕在列表中分开标注（AI 轨道带「· AI」标记）；播放控制栏新增字幕开关，可在「播放设置 → 字幕」中切换轨道或关闭字幕，选择会被记住。
- **画面校准**：升级后首次启动会提示校准一次，用方向键把四个角上的标记线推到电视的可见边缘，确认键依次切换四个角，最后点「已完成」保存。之后可以随时在「设置 → 设备信息 → 画面校准」重新调整。
- **隐私提示与开关**：首次启动显示欢迎提示与《用户协议与隐私政策》入口；设置新增「隐私与数据」分区，可分别关闭「崩溃跟踪」与「使用情况统计」。这两项用于收集匿名崩溃堆栈和基础使用事件（如页面浏览、播放开始与结束），不包含账号或媒体内容。

## 🐛 Bug Fixes

- **最近投屏封面空白**：B 站图片服务要求请求携带来源信息，旧版本直接请求会被拒绝，只显示占位底色；现在封面可以正常加载。
- **手机端拖动进度被拒绝**：点播与 HDR 内容播放时，电视按并未在用的播放器报告「能否拖动进度」，手机 B 站 App 拖动进度可能被拒绝；现在改为按当前实际播放的播放器判断。
- **放大的卡片被裁切**：焦点落在「最近投屏」第一张或最后一张卡片时，放大后的卡片边缘不再被列表裁掉。

## ⚠️ Breaking Changes

- **直播与单流旧片源的播放内核更换**：直播流和只提供单一视频流的旧片源此前由应用内置的 libVLC 播放，现在统一交给电视的系统解码器，与其他片源使用同一套播放流程，安装包也因此从约 58 MB 缩减到约 18 MB。少数电视上，这类片源可能因系统解码器不支持而无法播放。
- **设置页只读信息精简**：投屏地址、房间名、投屏通道和默认画质这几行说明不再显示在设置页，投屏功能与画质选择方式本身没有变化。
- **播放控制栏按钮调整**：倍速按钮移到播放 / 暂停按钮旁，右侧按钮组改为清晰度、字幕、弹幕和设置入口。

## 使用提示

- 画面校准只调整视频画面本身，弹幕会跟随视频位置一起移动；界面文字和字幕仍按电视的原生显示区域绘制。想恢复原样时重新校准，把四个角移回屏幕边缘即可。
- HDR、杜比视界和受 DRM 保护的内容仍直接输出画面，不经过校准后的处理流程。
- 校准使用一段 4K 测试画面比对边缘，电视无法解码时会提示并跳过。
- 首次启动的校准提示只出现一次，跳过后仍可从设置中再次打开。
- 字幕目前只在点播视频中提供，直播没有字幕。人工字幕优先，AI 字幕需要时可在字幕列表中手动选择；没有字幕的片源，控制栏的字幕按钮会变灰。
- 侧边栏打开后不会自动收起，按返回键或右键关闭。
