# Release v0.2.0

## Highlights

本版本重做了电视端界面：首页、侧边栏和设置页换成统一的深色玻璃风格，首页大图与最近投屏联动；同时新增画面校准，可以自行修正电视把画面边缘裁掉（过扫描）的问题。

## ✨ New Features

- **全新界面风格**：首页、侧边栏、弹窗、按钮和播放控制栏使用同一套深色玻璃材质，整体配色由高饱和粉色改为低饱和冷色；宽屏下页面内容改为居中窄栏排列，电视桌面的应用横幅换成 16:9 横版图，品牌标识改为矢量绘制，高分辨率下不再发虚。
- **首页联动最近投屏**：焦点移到「最近投屏」中的某条记录时，首页大标题、背景封面和主按钮会一起切换到这一条，并显示「刚刚」「N 分钟前」「昨天」等相对时间。
- **悬浮侧边栏**：在页面左边界按左键即可呼出侧边栏，它以浮层形式覆盖在当前页面上、背景自动变暗，按返回键或右键收起。
- **设置页重新分区**：分成账号信息、软件信息、设备信息三块。账号区用平台卡片显示登录状态，未登录时只保留一个扫码登录入口；软件版本会同时显示 Android 版本号，例如 `0.2.0 (15)`。
- **扫码登录改为首页弹窗**：登录不再是进入应用前的一整页，二维码弹窗直接覆盖在首页上，可以随时关闭；未登录时首页显示「访客模式」，仍能看到最近投屏并使用投屏帮助。
- **画面校准**：升级后首次启动会提示校准一次，用方向键把四个角上的标记线推到电视的可见边缘，确认键依次切换四个角，最后点「已完成」保存。之后可以随时在「设置 → 设备信息 → 画面校准」重新调整。

## 🐛 Bug Fixes

- **直播弹幕消失**：切换直播间、或点播与直播交替播放后，弹幕可能整场不再出现；现在每次进入新的直播会话都会重置弹幕时间轴。
- **最近投屏封面空白**：B 站图床要求请求带上来源信息，旧版本直接请求会被拒绝，封面只剩占位底色；现在封面可以正常显示。
- **聚焦卡片被裁切**：遥控器停在「最近投屏」首尾卡片时，放大后的卡片边缘不再被列表裁掉。
- **低版本 Android 上的玻璃面板**：电视系统不支持背景模糊时，半透明面板不再退化成一块纯色，改用软件模糊近似磨砂效果。

## ⚠️ Breaking Changes

- **设置页只读信息精简**：投屏地址、房间名、投屏通道和默认画质这几行说明不再显示在设置页，投屏功能与默认画质的选择方式本身没有变化。

## 使用提示

- 校准只调整视频画面本身，弹幕会跟随视频位置一起移动；界面按钮和文字仍按电视的原生显示区域绘制。想恢复原样时重新校准，把四个角移回屏幕边缘即可。
- HDR、杜比视界和受 DRM 保护的内容仍直接输出画面，不经过校准后的处理流程。
- 校准需要电视能解码 4K 视频，初始化失败时会给出提示并跳过。
- 侧边栏打开后不会自动收起，按返回键或右键关闭。
- 首次启动的校准提示只出现一次，跳过后仍可从设置中再次打开。
