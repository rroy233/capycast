# Release v0.2.1

## Highlights

本版本修复了投屏视频播放到一半因地址过期而中断的问题：地址失效时会自动重新获取，并从原来的位置继续播放。同时，电视音量不再受手机端投屏时的音量指令影响。

## 🐛 Bug Fixes

- **投屏中途提示播放失败**：点播视频播放一段时间后，B 站为片源签发的媒体地址会失效（服务器返回 403）。旧版本会直接跳到播放失败页，用户需要重新投屏一次；现在应用会自动重新获取地址，并从原来的位置、清晰度和音轨继续播放，刷新过程中不会重复发起请求，刷新后画面稳定前也不会再次触发。
- **电视音量被手机端改变**：旧版本会执行手机 B 站 App 投屏时下发的音量指令，手机端的音量设置会直接改变电视音量；现在电视音量只由电视遥控器控制。

## ⚠️ Breaking Changes

- **手机端不再能调整电视音量**：投屏时手机 B 站 App 的音量操作不再作用于电视，电视音量需要直接用电视遥控器调整。

## 使用提示

- 地址自动刷新只在点播内容中生效，直播投屏仍按原有方式恢复。
- 刷新时会重新打开播放器，画面可能短暂停顿后从原位置继续。
- 电视音量现在只用遥控器调整；投屏时手机 App 上的音量滑杆不再影响电视。
