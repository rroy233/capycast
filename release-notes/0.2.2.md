# Release v0.2.2

## Highlights

本版本新增界面语言选择（简体中文 / 繁體中文 / English），并支持登录 Bilibili 国际版账号，与国内版账号分别保存、随时切换；设置页还新增了「问题反馈」入口。

## ✨ New Features

- **界面语言选择**：在「设置 → 软件信息 → 语言设置」中可选择「跟随系统 / 简体中文 / 繁體中文 / English」，切换后界面立即重新载入，重启电视后仍保持该语言。首页、设置、登录、侧边栏、各类弹窗和播放控制栏的文字都会跟随语言变化，《用户协议与隐私政策》也提供英文与繁体中文版本。Android 13 及以上还可以在系统设置中单独为本应用指定语言。
- **Bilibili 国际版账号**：设置页账号区新增平台卡片，可在「Bilibili国内版」与「Bilibili国际版」之间切换，每张卡片显示自己的登录状态，两个账号可以同时保持登录。国际版账号同样用扫码方式登录，登录后可正常投屏点播视频，观看记录与播放进度会记到当前所选账号上。
- **问题反馈入口**：在「设置 → 软件信息 → 问题反馈」打开反馈面板，可在 GitHub 与 Email 两个渠道间切换，用手机扫描二维码即可打开 GitHub Issue 表单或写邮件；面板会同时显示当前软件版本，方便说明所用的版本。局域网诊断页也增加了直达 GitHub Issue 的入口。
- **更新说明跟随语言**：应用内的更新摘要与完整更新说明会按当前界面语言显示，不再固定为中文。

## ⚠️ Breaking Changes

- **界面语言默认跟随电视系统语言**：此前界面固定为简体中文，现在默认读取电视的系统语言。如果系统语言是英文或繁体中文，升级后会显示对应语言的界面，可以在「设置 → 软件信息 → 语言设置」中改回简体中文。

## 使用提示

- 切换语言会重新载入界面，正在播放的视频会中断，需要重新投屏一次。
- 升级前已有的登录状态会自动迁移到「Bilibili国内版」，不需要重新扫码。
- 直播投屏仍然需要国内版账号的 TV 登录凭据：当前为国际版账号或未登录时，直播会提示切换到已登录的国内版账号后重试；点播投屏两种账号都可以使用。
- 国内版与国际版的登录状态和观看记录分别保存，切换平台后新的投屏会使用切换后的账号。
- 检查更新与下载安装过程中的提示，以及部分播放相关提示目前仍为中文，尚未跟随语言切换。
