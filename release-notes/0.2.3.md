# Release v0.2.3

## ✨ New Features

- **合集视频自动连播**：投屏 B 站合集中的视频时，播放开始并收起播放控制栏后，右下角会提示「当前视频来自一个合集」，可在 5 秒内按遥控器确认「开启自动连播」。开启后当前视频播完会直接接着播放下一个：多分 P 视频先播下一个分 P，再播合集里的下一个视频，全过程中不需要再用手机操作。忽略提示或等倒计时结束则保持原有行为。

## 使用提示

- 提示只在视频确实属于合集时出现，每次投屏最多询问一次。
- 自动连播只对本次投屏生效，不会沿用到之后的投屏；更换投屏内容、停止投屏、播放出错或重新打开应用后，都需要再次开启。
- 开启后，视频结束前 5 秒会提示「即将播放下一个视频」；接播的每个视频都会作为独立的一次观看记录。
- 提示显示期间，遥控器的方向键中间键 / 确认键用于提示中的按钮，不会调出播放控制栏。
- 自动连播适用于普通投稿视频；番剧、影视等 PGC 内容以及直播保持原有行为。
