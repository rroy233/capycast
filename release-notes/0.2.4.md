# Release v0.2.4

## Highlights

本版本让投屏播放更贴合电视的实际解码能力：点播会优先选择电视硬件解码器支持的编码，播放持续卡顿时自动换用其他编码；弹幕与画面重新对齐，应用离开前台后也不再继续播放声音。

## ✨ New Features

- **按电视解码能力选择编码**：同一画质下若有多种编码的线路（H.264 / HEVC / AV1），会优先选择电视能硬件解码的那一条，减少出现「线路有了却播不动」的情况；画质列表中显示的编码也是实际使用的编码。AV1 编码的线路现在也会出现在画质选项中。
- **卡顿自动换编码**：播放中持续掉帧时，会在当前画质下自动换用其他可解码的编码，并从当前进度继续播放，画质档位保持不变。如果该画质已经没有其他可用编码，会提示「当前画质播放不流畅，暂无其他可用编码」。

## 🐛 Bug Fixes

- **弹幕与画面同步**：修复弹幕可能落后于画面、与画面错位的问题，例如画面短暂卡顿或调整播放倍速之后；弹幕现在按视频时间轴调度，暂停、跳转和变速后都保持一致。
- **离开前台后不再继续出声**：按首页键、切换到其他应用或关闭电视屏幕时，正在播放的视频会暂停并释放播放器，不再在后台播放声音和占用解码资源；返回应用后会恢复到原来的进度、倍速和音量。

## 使用提示

- 回到应用后播放处于暂停状态，按一次播放键即可继续；恢复时会以暂停状态重新打开视频，可能需要短暂缓冲。
- 应用处于后台时，手机端的投屏与遥控操作不会生效，回到应用后再操作即可。
