# Release v0.2.2

## Highlights

This release adds an interface language setting (简体中文 / 繁體中文 / English) and support for Bilibili international accounts, which are stored separately from your domestic account and can be switched at any time. Settings also gains a Feedback entry.

## ✨ New Features

- **Interface language selection**: Settings → Software → Language lets you choose Follow System / 简体中文 / 繁體中文 / English. The interface reloads immediately and keeps the choice after a restart. Home, settings, login, the sidebar, dialogs and the playback HUD all follow the selected language, and the User Agreement & Privacy Policy is now available in English and Traditional Chinese. On Android 13 and above you can also pick a language for this app from the system settings.
- **Bilibili international accounts**: The account section of Settings now shows a platform card for each of Bilibili (China) and Bilibili (International). Each card reports its own login state, and both accounts can stay logged in at once. International accounts sign in with the same QR-code flow and can cast on-demand videos, with watch history and progress reported to the account you selected.
- **Feedback entry**: Settings → Software → Feedback opens a panel where you can switch between GitHub and Email; scan the QR code with your phone to open the GitHub issue form or write an email. The panel also shows the current version so you can mention which build you are on. The LAN diagnostics page now links straight to the GitHub issue form as well.
- **Release notes follow the language**: The in-app update summary and the full release notes are shown in the selected interface language instead of always Chinese.

## ⚠️ Breaking Changes

- **The interface language now follows the TV system language by default**: The interface used to be fixed to Simplified Chinese and now reads the system language. If your TV is set to English or Traditional Chinese, the app will use that language after the update; you can pin it back to Simplified Chinese in Settings → Software → Language.

## Usage Notes

- Switching the language reloads the interface and interrupts the current playback, so you need to cast again.
- Existing logins are migrated to Bilibili (China) automatically after the update; no need to scan again.
- Live casting still requires the TV credential of a domestic account: while an international account is selected or no account is logged in, live playback asks you to switch to a logged-in domestic account and retry. On-demand casting works with either account.
- Login state and watch history are stored separately for the domestic and international accounts, and new casts use whichever platform is selected.
- Messages shown while checking for updates, downloading and installing, and some playback-related messages are still Chinese and do not follow the language setting yet.
