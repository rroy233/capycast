# Release v0.2.2

## Highlights

本版本新增介面語言選擇（简体中文 / 繁體中文 / English），並支援登入 Bilibili 國際版帳號，可與國內版帳號分別保存、隨時切換；設定頁也新增了「問題回饋」入口。

## ✨ New Features

- **介面語言選擇**：在「設定 → 軟體資訊 → 語言設定」中可選擇「跟隨系統 / 简体中文 / 繁體中文 / English」，切換後介面會立即重新載入，重新啟動電視後仍會保留此設定。首頁、設定、登入、側邊欄、各類彈窗與播放控制列的文字都會跟隨語言變化，《使用者條款與隱私政策》也提供英文與繁體中文版本。Android 13 以上還可以在系統設定中單獨為本應用程式指定語言。
- **Bilibili 國際版帳號**：設定頁帳號區新增平台卡片，可在「Bilibili 國內版」與「Bilibili 國際版」之間切換，每張卡片顯示各自的登入狀態，兩個帳號可以同時保持登入。國際版帳號同樣以掃碼方式登入，登入後可正常投屏隨選影片，觀看紀錄與播放進度會記到目前所選的帳號上。
- **問題回饋入口**：在「設定 → 軟體資訊 → 問題回饋」開啟回饋面板，可在 GitHub 與 Email 兩個管道間切換，用手機掃描 QR Code 即可開啟 GitHub Issue 表單或撰寫郵件；面板會同時顯示目前軟體版本，方便說明所用的版本。區域網路診斷頁也增加了直達 GitHub Issue 的入口。
- **更新說明跟隨語言**：應用程式內的更新摘要與完整更新說明會依目前介面語言顯示，不再固定為中文。

## ⚠️ Breaking Changes

- **介面語言預設跟隨電視系統語言**：先前介面固定為簡體中文，現在預設讀取電視的系統語言。如果系統語言是英文或繁體中文，升級後會顯示對應語言的介面，可以在「設定 → 軟體資訊 → 語言設定」中改回簡體中文。

## 使用提示

- 切換語言會重新載入介面，正在播放的影片會中斷，需要重新投屏一次。
- 升級前既有的登入狀態會自動移轉到「Bilibili 國內版」，不需要重新掃碼。
- 直播投屏仍然需要國內版帳號的 TV 登入憑證：目前為國際版帳號或未登入時，直播會提示切換到已登入的國內版帳號後重試；隨選影片投屏兩種帳號都可以使用。
- 國內版與國際版的登入狀態與觀看紀錄分別保存，切換平台後新的投屏會使用切換後的帳號。
- 檢查更新與下載安裝過程中的提示，以及部分播放相關提示目前仍為中文，尚未跟隨語言切換。
