# Release v0.2.3

## ✨ New Features

- **合集影片自動連播**：投屏 B 站合集中的影片時，播放開始並收起播放控制列後，右下角會提示「目前影片來自一個合集」，可在 5 秒內按遙控器確認「開啟自動連播」。開啟後目前影片播完會直接接著播放下一個：多分 P 影片先播下一個分 P，再播合集裡的下一個影片，全程不需要再用行動裝置操作。忽略提示或等倒數結束則維持原有行為。

## 使用提示

- 提示只在影片確實屬於合集時出現，每次投屏最多詢問一次。
- 自動連播只對本次投屏生效，不會沿用到之後的投屏；更換投屏內容、停止投屏、播放發生錯誤或重新開啟應用程式後，都需要再次開啟。
- 開啟後，影片結束前 5 秒會提示「即將播放下一個影片」；接播的每個影片都會作為獨立的一次觀看紀錄。
- 提示顯示期間，遙控器的方向鍵中間鍵／確認鍵用於提示中的按鈕，不會叫出播放控制列。
- 自動連播適用於一般投稿影片；動畫、影視等 PGC 內容以及直播維持原有行為。
