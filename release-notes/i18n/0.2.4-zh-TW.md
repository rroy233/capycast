# Release v0.2.4

## Highlights

本版本讓投屏播放更貼合電視的實際解碼能力：隨選影片會優先選擇電視硬體解碼器支援的編碼，播放持續卡頓時自動換用其他編碼；彈幕與畫面對齊，應用程式離開前景後也不再繼續播放聲音。

## ✨ New Features

- **依電視解碼能力選擇編碼**：同一畫質下若有多種編碼的線路（H.264 / HEVC / AV1），會優先選擇電視能硬體解碼的那一條，減少出現「線路有了卻播不動」的情況；畫質清單中顯示的編碼也是實際使用的編碼。AV1 編碼的線路現在也會出現在畫質選項中。
- **卡頓自動換編碼**：播放中持續掉幀時，會在目前畫質下自動換用其他可解碼的編碼，並從目前進度繼續播放，畫質檔位維持不變。如果該畫質已經沒有其他可用編碼，會提示「目前畫質播放不流暢，暫無其他可用編碼」。

## 🐛 Bug Fixes

- **彈幕與畫面對齊**：修正彈幕可能落後於畫面、與畫面錯位的問題，例如畫面短暫卡頓或調整播放倍速之後；彈幕現在依影片時間軸排程，暫停、跳轉和變速後都保持一致。
- **離開前景後不再繼續出聲**：按下首頁鍵、切換到其他應用程式或關閉電視螢幕時，正在播放的影片會暫停並釋放播放器，不再於背景播放聲音和佔用解碼資源；返回應用程式後會恢復到原本的進度、倍速和音量。

## 使用提示

- 回到應用程式後播放處於暫停狀態，按一次播放鍵即可繼續；恢復時會以暫停狀態重新開啟影片，可能需要短暫緩衝。
- 應用程式處於背景時，手機端的投屏與遙控操作不會生效，回到應用程式後再操作即可。
